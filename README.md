# 🧠 Linux System Programming (LSP) Assignments

## 📌 Description

This repository contains a collection of **Linux System Programming (LSP) assignments implemented in C**.

The project focuses on **low-level system interactions** using Linux APIs and system calls, helping to understand how user-space programs interact with the operating system.

---

## 🎯 Objectives

* Understand Linux system calls
* Learn process and file management
* Work with directories and permissions
* Explore `/proc` filesystem
* Build strong foundation in system-level programming

---

## 🚀 Features

* 📂 File handling using system calls (`open`, `read`, `write`)
* 📁 Directory operations (`opendir`, `readdir`)
* ⚙️ Process handling (`getpid`, `/proc`)
* 📊 File metadata (`stat`)
* 🔐 Permission handling
* 🧩 Modular assignment-based implementation

---

## 🛠️ Technologies Used

* Language: **C**
* Platform: **Linux (Ubuntu recommended)**
* Tools:

  * `gcc`
  * `make`
  * Linux terminal

### 🔹 Process Management

* Work with process IDs and system info

### 🔹 System Interaction

* Use kernel interfaces like `/proc`
